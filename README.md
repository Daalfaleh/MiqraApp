# MiqraApp

MiqraApp is an Android application focused on Islamic reading, prayer, and reference features. The repository contains the Android Studio project, an installable APK, screenshots, and a demonstration video.

## Project layout

- `Miqrah/` — Gradle-based Android source project
- `Miqrah.apk` — packaged application build
- `screenshots/` — interface previews
- `MirqahVid1.mp4` — demonstration recording

## Build

1. Open `Miqrah/` in Android Studio.
2. Allow Gradle to sync and install the requested Android SDK components.
3. Add any local API keys or secrets required by the Gradle configuration without committing them.
4. Build and run on an emulator or Android device.

Some bundled components and datasets retain their original attribution and licensing notices.
